Leonida Trophy Guide — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: official names, descriptions and grades, a guide in our own words with its sources beside every trophy, a roadmap to the platinum, missable flags, and a checklist saved in the browser with export/import, kind filters and a spoiler mode. No online trophies, no Rockstar artwork — the look is our own, and the app loads nothing from the network.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
